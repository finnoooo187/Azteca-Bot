# Azteca Bot

Discord bot with:
- `/zahl`: random number from 100,0 to 999,9
- Daily availability poll at 00:00 Europe/Berlin
- Voting until 20:30 Europe/Berlin
- Automatic result message at 20:30
- Votes are stored in `poll_data.json`

## Environment variable
Set `DISCORD_TOKEN` to the Discord bot token in the hosting provider. Do not put the token in GitHub.

## Channel
The daily poll is sent to channel ID `1009507301692014665`.
