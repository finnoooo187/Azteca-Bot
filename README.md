# Azteca Bot

Discord-Bot für den Azteca-Server.

## Funktionen

- `/zahl` erzeugt eine zufällige Zahl von `100,0` bis `999,9`.
- Tägliche Aufstellung automatisch um `00:00 Uhr` (Europe/Berlin).
- Abstimmung:
  - 🟢 Verfügbar
  - 🔴 Nicht verfügbar
  - 🟡 Vielleicht
- Die Namen der Abstimmenden werden direkt im Embed angezeigt.
- Eine Person kann ihre Auswahl jederzeit ändern.
- Die Abstimmung wird um `20:30 Uhr` automatisch geschlossen.
- Nach dem Schließen bleiben die Namen und Ergebnisse sichtbar.
- Der Bot verwendet den Discord-Kanal `1009507301692014665`.

## Wichtig

Der Discord-Bot-Token darf niemals in diese Dateien oder in GitHub eingetragen werden.

Der Hoster muss den Token als Umgebungsvariable mit dem Namen `DISCORD_TOKEN` bereitstellen.
